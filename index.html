Welcome to my narrative design portfolio! This page features four assignments I created for my Interactive Writing course. They cover character development, game dialogue, worldbuilding, and interactive storytelling.

Projects

Pulse — Character Design Document

For this assignment, I created Pulse (Amara Okafor), an original support character for the Overwatch universe. The document covers her backstory, personality, goals, relationships, and sample dialogue. It shows how I develop a consistent character and writing voice.

View Character Design Document

Echo — Voice Lines

I wrote a set of voice lines for Echo (Maya Reyes), an original agent designed for the VALORANT universe. The lines change depending on gameplay triggers, such as using an ability, getting a kill, or respawning. This assignment shows how I write short, reactive dialogue while keeping a character's voice consistent.

View Voice Lines Spreadsheet

The Signal Wars — Historical Spine

This worldbuilding assignment develops a timeline for a story set in the Overwatch universe. It follows the rise of surveillance technology, the creation of the Aegis network, and the conflicts that follow. It demonstrates how I connect historical events, characters, and larger story conflicts.

View Historical Spine

The Last Train — Interactive Dialogue

I created an interactive conversation in Ink where the player decides whether to help a stranger find a lost wallet and train ticket before the last train leaves. The script uses choices, variables, and different endings. This project shows my experience with branching dialogue and interactive narrative scripting.

Download Ink Script

The Ink file can be opened in an Ink editor to read or test the dialogue.

Pulse, The Signal Wars, and Echo are unofficial fan-created course projects, not affiliated with Blizzard Entertainment or Riot Games.
